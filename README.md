# 求真社 · Verifact

> 一条传言，一份卷宗。
> WaytoAGI 1024 切磋大会 · 侦探赛道 ｜ 驱动：元宝搜索

把家族群、短视频、朋友圈里那条"听起来很真"的话交进来，
求真社把它拆成一条条可以查的线索，派侦探去全网搜证据，带来源回来，盖一个章。
**查不到的，说查不到。**

## 怎么用

浏览器打开上面的链接，或双击本地 `index.html`（零依赖、离线可开、无构建）。

三种委托方式：

1. **粘贴文字** —— 把传言原话贴进输入框，点「委托调查」
2. **上传截图** —— 点「📷 上传截图查证」，丢一张家族群截图进去
3. **一键演示** —— 点下面三个内置案例，直接看完整调查过程

右上角「接入元宝搜索」填入 Endpoint 与 Key 后，切换为实时检索模式。
**未接入时系统只演示流程，不对任何新输入编造结论** —— 这就是"少点幻觉"的产品化表达。

## 三个内置案例

| 案例 | 结论 | 看点 |
|---|---|---|
| 🍈 空腹吃荔枝会得荔枝病，严重的会致死 | 🟡 部分属实（夸大） | 同一句话，三条线索分开盖章 |
| 📡 微波炉加热的食物会致癌 | 🔴 不实 | 但"塑料容器有风险"判了属实 —— 不一律否定 |
| 🥬 每天一杯芹菜汁能把血压降到正常 | ⚪ 查无实据 | 敢说不知道 |

## 功能

- **断言拆解**：不整段下结论，拆成可独立验证的线索逐条盖章
- **四档结论**：属实 / 不实 / 部分属实 / 查无实据
- **反向举证**：每条线索跑 4 组检索式，含主动搜"辟谣 谣言"
- **来源分级**：T1 官方机构 → T4 自媒体，单独的自媒体不作定论依据
- **反驳卡片**：Canvas 生成 1080×1440 图，可存图、可复制文字，直接甩回群里
- **盯梢名单**（进阶）：每日自动重查，结论变化即提醒
- **报告导出**（进阶）：一键导出带证据链的 Markdown 调查报告
- **截图查证**（进阶）：上传截图 → 识别 → 逐句核验

## 关于搜索

元宝搜索是本作品的心脏：所有结论 100% 来自检索，去掉它这个作品一秒都转不起来。
检索层在 `index.html` 中的 `SearchAdapter`，替换 `endpoint` 与 `apiKey` 两个字段即可切换到实时模式。

DEMO 模式下的来源站点真实存在且可访问，但精确文章 URL 未伪造，由实时检索返回。
