# STORY.md — 求真社 · Verifact 路演（3 分钟）

## ① 用户意图对齐

- **目标受众**：WaytoAGI 1024 切磋大会**侦探赛道评委 + 现场观众**。场合 = 3 分钟路演 + 大屏展示，评分维度固定为完成度 30% / 创意 25% / 场景价值 25% / 展示 20%。评委是见过大量 AI 演示的人，对"又一个套壳问答"高度免疫。
- **核心目标**：讲完后评委要相信三件事 —— ① **搜索是这个作品的心脏**，去掉元宝搜索它一秒都转不起来；② 记住两个机制：**断言拆解**（同一句话真假分开盖章）与**查无实据**（敢说不知道）；③ 当场想打开链接亲手试一遍。
- **PPT 长度**：12 页（3 分钟，约 15 秒/页）。Hero 配额 = 3 页（封面 / 第 3 页核心机制 / 结束页），占 25%。
- **视觉调性**：档案卷宗 · 牛皮纸 · 朱砂印章 · 打字机 · 克制克制。文案一律短句、口语、不做形容词堆砌。
- **内容边界**：
  - 必讲：痛点、断言拆解、四档结论、反向举证 + 来源分级、三个进阶、反驳卡片、元宝搜索地位、评分维度对应。
  - 不讲：代码实现、API 参数、工程量、团队分工。
  - 禁碰：时政、个人隐私、对具体个人的指控；不出现任何未经核实的真实传言指控。

## ② 页面布局骨架

- **无目录页**（3 分钟路演不做目录，直接进入），因此全篇**无 `type: section` 章节扉页**，不存在目录↔扉页契约问题。
- **Hero 页定位**：01 封面（hero）、03 断言拆解（hero）、12 结束页（hero）。三者之间均间隔 ≥ 1 个 supporting 页 ✔
- **rhythm 曲线**：peak(01) → valley(02) → **peak(03)** → valley(04) → valley(05) → valley(06) → **peak(07)** → valley(08) → **peak(09)** → valley(10) → valley(11) → peak(12)。无连续 ≥3 valley。
- **非对称版式预算**：02 / 03 / 05 / 06 / 07 / 08 / 10 / 11 共 8 页非对称（67% ≥ 40% ✔）
- **对称版式预算**：内页仅 04（四卡片横排）、09（居中巨型数字）两页使用对称版式；01 封面与 12 结束页为自定义全屏版式（豁免）。
- **版式多样性**：`左大图+右侧文字`(02) + `非对称双栏`(03,10) = 3 页，占 25% ≤ 40% ✔

### 数据落点核对（含数据的页已补判断）

- 02：传言每天在跑 → **判断**：答案只在今天的网络上，模型凭记忆答必错，所以"去搜"是刚需而非加分项。
- 03：三条线索 2 真 1 假 → **判断**：整段下结论必然误判，拆解是唯一正确姿势。
- 06：三个案例三种结论 → **判断**：不一律否定、不强行给答案，才叫核查。
- 09：100% → **判断**：去掉搜索这个作品一秒都转不起来，这就是赛道规则里"去掉就转不起来"的硬要求。
- 10：权重 30/25/25/20 → **判断**：展示不是附属项，占 20%，所以整套视觉与落章动画都是得分动作。
