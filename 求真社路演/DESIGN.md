# DESIGN.md — 求真社 · Verifact 路演

## 0. 风格判定

不命中 academic / consulting / redgold 任一垂直领域（场景 = 产品路演 + 创意展示）→ **走通用设计原则**，由需求自由设计。
视觉文化取自「人文 / 哲学 / 文化」参考色系（宣纸米 + 松烟墨 + 朱砂 + 青墨），与作品本体 `index.html` 的档案卷宗风完全同源。

**调性关键词**：档案卷宗 · 牛皮纸 · 朱砂印章 · 打字机 · 克制克制

---

## 1. 画布与全局母版（具体 px）

- 画布 **1280 × 720**（16:9）
- 页面 padding：**上 20 / 下 20 / 左 72 / 右 72**
- **A · 标题块**：`y = 20–120`（高 100）｜主标题 34px bold 宋体，左对齐；标题左侧有 5×20px 朱砂竖条（距标题 12px）
- **B · 内容区**：`y = 120–660`（可用高 540）
- **C · 页脚条**：`y = 660–700`（高 40）｜左侧「求真社 · Verifact」12px 青墨 60% 透明；右侧页码 `NN / 12` 12px 青墨
- 封面（01）与结束页（12）使用自定义全屏版式，**不套 A/B/C 三区**

**语义色扩展声明（必要）**：四档结论沿用**作品本体 `index.html` 的既有语义色** —— 属实 `#2E6B4F`、不实 `#A8351A`、部分属实 `#B6690E`、查无实据 `#3F4A55`。这不是新增装饰色，而是产品已定义的结论语义，**改色会导致 PPT 与作品视觉不一致**，故列为四色池之外的必要扩展，仅出现在结论印章 / 结论标签上，不作背景或大面积铺色。

**半透明与渐变**
- 纸片容器：`background: '#FDFCF7'`（宣纸米提亮一档，视作 `#F4F1E9` 的明度变体）
- 卡片浮起：`boxShadow: '0 4px 20px rgba(26,26,26,0.08)'`
- 背景大印章装饰：朱砂 `opacity: 0.06`（仅 01 / 12 使用）
- 分隔线：`borderBottom: '1px dashed rgba(63,74,85,0.30)'`
- **禁止**：渐变铺满、高饱和撞色、同一页出现第二套色板

## 3. 字体系统（2 套家族）

| 层级 | 字体 | 字号 | 字重 | 行高 |
|:---|:---|:-:|:-:|:-:|
| 封面主标题 | **Songti SC** | 68px | bold | 1.2 |
| 章节/结束大字 | Songti SC | 56px | bold | 1.15 |
| **巨型锚点数字** | Songti SC | 96–120px | bold | 1.0 |
| 页面主标题（A 区） | Songti SC | 34px | bold | 1.3 |
| 卡片小标题 | Songti SC | 26px | 600 | 1.4 |
| 正文 | **PingFang SC** | 20px | regular | 1.6 |
| 正文次级 / 说明 | PingFang SC | 17px | regular | 1.6 |
| 等宽标注（案号/检索式） | PingFang SC | 15px | regular | 1.5 |
| 页脚 / 页码 | PingFang SC | 12px | regular | 1.4 |

- 标题一律宋体，正文一律黑体（**允许且要求**标题与正文不同个性）
- 巨型数字必须用宋体 bold，与正文形成字体 + 字重双重对比
- 中文字距默认不加；英文案号（VERIFACT）加 `letterSpacing: 3`

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 主视觉占 B 区 |
|:---|:---|:-:|:-:|
| 封面 | 主标题 + 副标 + L1 印章 | 20 | ≥ 40% |
| 内容页 · 单主题 | 标题 + 正文 + L1 | **180** | ≥ 30% |
| 内容页 · 卡片组 | 标题 + 引导句 + N 卡 | 每卡 ≥ 80 | — |
| 结束页 | 金句 + 落款 + 印章 | 20 | ≥ 40% |

- **常规页留白上限 35%**；01 / 07 / 09 为 peak 页，允许 34–42%
- **容器填充率 ≥ 85%**：卡片内文字 + 标签垂直占用需撑满，尾部引文条用 `marginTop: 'auto'` 钉底
- **焦点留白**：巨型印章 / 巨型数字四周留 ≥ 40px 呼吸区
- **禁止"均匀稀薄"**：空白必须围绕锚点，不得平均散布

## 5. 配图系统（本项目全部为结构化 SVG，无摄影/插画）

> 判定依据：本 deck 的视觉载体全部是**机制图示**（拆解流程、印章、检索式、架构、UI 示意、表格、巨型数字），属于明确允许 SVG 的结构化 / 低语义元素；全篇无具象人物 / 场景 / 空间 / 摄影需求，故不使用 ImageGen，也不产生额外积分消耗。

| 等级 | 本项目载体 | 尺寸 | 位置 |
|:---|:---|:---|:---|
| **L1 · 主视觉** | 巨型朱砂印章、拆解流程图、卷宗三栏、反驳卡片实物、手机界面示意、巨型 100% | 占 B 区 ≥ 40%（常见 620×420 / 700×380） | 卡片整体背景 / 一栏铺底 |
| **L2 · 支撑图** | 四档小印章、检索式分支图、维度表格 | ≥ 280×180 | 段落旁 / 卡头 |
| **L3 · 母版徽标** | 页脚「求真社 · Verifact」文字标 + 朱砂竖条（A 区标题左） | ≤ 64 | **C 区左侧 + A 区标题左，全篇位置固定** |

**SVG 视觉规范（全篇统一）**
- 印章：双线圆环 + 宋体结论字 + 底部 `VERIFACT` 小字；朱砂描边 `#A8351A`，填充 `rgba(168,53,26,0.06)`；旋转 `-8°`
- 纸片：`#FDFCF7` 底 + `1px solid rgba(26,26,26,0.14)` + `0 4px 20px rgba(26,26,26,0.08)`
- 连线：`#3F4A55`，`strokeWidth 2`，关键路径朱砂
- 检索式：等宽风格，用 `<rect>` 灰底条 + 左侧 4px 朱砂标

## 7. 装饰白名单（全篇仅此四项）

1. **朱砂竖条**：A 区标题左侧 5×20px `#A8351A`（全篇位置固定）
2. **双线朱砂印章**：L1/L2 视觉载体，旋转 -8°
3. **虚线分隔**：`1px dashed rgba(63,74,85,0.30)`，用于卡内分区
4. **案号等宽小字**：`VERIFACT / VF-1024-0001` 形式，青墨 15px，`letterSpacing: 3`

**禁止**：emoji 图标、圆点列表符号堆砌、渐变按钮、拟物阴影、任何第二套色板。
